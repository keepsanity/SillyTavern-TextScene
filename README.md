# Text Scene

A SillyTavern extension for texting scenes without lengthy narration.

## Usage

- Open from the wand menu or type `/text`.
- Use `/text first=true` to let the character text first.
- Send messages one at a time, or use batch mode to send several before getting a reply.
- Add the full conversation, a summary, or both to your main RP.
- Use the scene menu to add context, request a closing reply, or view past scenes.

Closing the window keeps your conversation and draft. End the scene to start a new one next time.

Supports character chats only.

The UI follows SillyTavern’s language setting: Korean or English (fallback). Reload after changing languages. The RP insertion language is set separately.
